# Orbit Chrome UI

The native shell follows the visual mechanics in 360's `buttonTemplate.html`:

- `#0b0f19` dark surface
- `#f8fafc` primary chrome
- 1px low-alpha border
- 6px micro-radius
- fill-on-hover interaction
- scale-down press feedback

The browser chrome is native Iced/Rust UI, not an HTML page layered over web content.
